# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates the simple interest based on the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Example
Principal Amount = 1000
Rate of Interest = 5%
Time = 2 Years

Simple Interest = 100

## Features
- Calculates simple interest
- Easy to understand
- Simple input values
